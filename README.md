# Digital Store

## Description
Digital Store est une application web e-commerce développée en PHP et MySQL.  
Elle permet de gérer les produits, les catégories, le panier et les commandes.

## Technologies
- PHP
- MySQL
- PDO
- HTML/CSS

## Installation

1. Installer XAMPP
2. Copier le projet dans :
   C:\xampp\htdocs\p1
3. Démarrer Apache et MySQL
4. Importer la base de données via phpMyAdmin (fichier SQL fourni)
5. Accéder à :
   http://localhost/p1
